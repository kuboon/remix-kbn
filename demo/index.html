@remix-kbn packages demo

Live demos of packages published from kuboon/remix-kbn to jsr.io/@remix-kbn.

@remix-kbn/dragology @remix-kbn/ui-pinch-pan @remix-kbn/helper-agent

@remix-kbn/dragology

Dragology's declarative SVG dragging on Remix v3: each picture is a function of its state, and a drag spec says which states an element can be dragged between. Drag the knobs, handles and list items.

@remix-kbn/ui-pinch-pan

Pinch, pan and wheel as a @remix-run/component mixin. On a touchscreen, pinch and pan with two fingers. On a trackpad, two-finger scroll pans and a pinch zooms about the cursor. With a mouse, the wheel pans and Ctrl / ⌘ + wheel zooms. The buttons drive the same view through the mixin's controls.

@remix-kbn/helper-agent

An in-page support chat: the panel, a fetch-router route, and an agent behind it. GitHub Pages has no server, so here the route runs on a router in the page with the scripted dummyAgent behind it — the stream and both kinds of tool (one the route runs, one the page runs, and pointing at an element) are real; only the model is missing.
